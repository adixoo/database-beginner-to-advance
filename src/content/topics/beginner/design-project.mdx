Time to use everything: a database for a small shop where customers order products. Run each step in your course database in [Sequill](https://sequill.adibitz.com/app): the shop gets its own tables next to the Instagram ones.

## Plan the tables

Four things, four tables. One order holds many products and one product sits in many orders, so `order_items` is the [junction table](/beginner/table-relationships#many-to-many) between them.

<ShopPlan />

- Every table has a [primary key](/beginner/keys#primary-keys); `order_items` uses the pair `(order_id, product_id)`.
- Prices are whole cents, an `INTEGER`, so money never rounds ([Data types](/beginner/data-types)).

## Create the tables

```sql
PRAGMA foreign_keys = ON;

CREATE TABLE customers (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE
);

CREATE TABLE products (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  price_cents INTEGER NOT NULL CHECK (price_cents >= 0)
);

CREATE TABLE orders (
  id INTEGER PRIMARY KEY,
  customer_id INTEGER NOT NULL REFERENCES customers (id),
  ordered_on TEXT NOT NULL
);

CREATE TABLE order_items (
  order_id INTEGER NOT NULL REFERENCES orders (id),
  product_id INTEGER NOT NULL REFERENCES products (id),
  quantity INTEGER NOT NULL CHECK (quantity > 0),
  PRIMARY KEY (order_id, product_id)
);
```

## Ask questions

What is in each order? Join all four tables:

```sql
SELECT orders.id, customers.name AS customer, products.name AS product, order_items.quantity
FROM order_items
JOIN orders ON orders.id = order_items.order_id
JOIN customers ON customers.id = orders.customer_id
JOIN products ON products.id = order_items.product_id
ORDER BY orders.id, products.name;
```

|  id | customer | product  | quantity |
| --: | -------- | -------- | -------: |
|   1 | Asha     | Mug      |        2 |
|   1 | Asha     | Pen      |        1 |
|   2 | Ravi     | Notebook |        1 |
|   3 | Asha     | Notebook |        3 |

How much has each customer spent? Group by customer and add up quantity × price:

```sql
SELECT customers.name, SUM(order_items.quantity * products.price_cents) AS total_cents
FROM customers
JOIN orders ON orders.customer_id = customers.id
JOIN order_items ON order_items.order_id = orders.id
JOIN products ON products.id = order_items.product_id
GROUP BY customers.id
ORDER BY total_cents DESC;
```

## Words to know

<WordsToKnow>

- **CHECK**
  A rule that rejects values that fail a test, such as a quantity of 0.
- **Junction table**
  A table in between that links two tables many-to-many.
- **Schema**
  The plan for your tables: columns, types, keys and rules.

</WordsToKnow>
